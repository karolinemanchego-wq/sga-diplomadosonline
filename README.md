# sga-diplomadosonline
DiplomadosOnline ha visto un crecimiento en su plantilla estudiantil y ahora tiene miles de alumnos, sin embargo, siguen dependiendo de anotarlo todo en un archivo de Excel, lo que ha ocasionado un caos debido a que hay muchos errores al escribir los nombres, las cedulas se repiten y el archivo se puede llegar a dañar o cerrar mal, perdiendo todo el trabajo porque no tienen un respaldo seguro. 
El sistema debe de tener un menú con 7 opciones que permita registrar a los alumnos con sus datos básicos, como nombre, cedula y correo, también se debe poder anotar las notas y a su vez brindar la opción de deshacer en caso de escribir una calificación de forma incorrecta. Lo más importante es que el programa pueda ser capaz de reconocer solo los aprobados según el tipo de programa que realizo (curso, diplomado y Bootcamp).
